# One-off 3D Projects

Small, practical 3D models and quick prototypes.

## Included

- `models/x1c-whiteboard-markers/`
  - Language-agnostic status markers for whiteboard use
  - Sized under a US dime in width
  - Variants with magnet press-fit pocket

## Notes
